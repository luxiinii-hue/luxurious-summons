# Luxurious Summons

A Foundry VTT V14 module for managing playable companion characters in D&D 5e — clone-based summons (Simulacrum, Mirror Image, Echo Knight Echo), template-based summons (Find Familiar, Animate Dead, Beast Companion, etc.), and a custom-template editor. Visual customization via PIXI filters; per-template fancy death animations; click-to-place tile selection; per-master folder organization in the Actor directory.

## Install

1. Drop the `luxurious-summons` folder into Foundry's `Data/modules/` (path shown on Foundry's Setup screen as "User Data Path").
2. Activate the module in your world (Game Settings → Manage Modules).
3. Click the new ghost icon in the left scene-controls toolbar to open the Companion Manager.

Requires the `dnd5e` system (v3+).
